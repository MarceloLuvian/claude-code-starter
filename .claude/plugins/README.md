# plugins/

Un **plugin** empaqueta `agents` + `commands` + `hooks` (y skills) en un solo pack: lo instalas una vez y
queda disponible siempre; lo compartes entre proyectos y equipo.

Aquí va `optimus/` como **ejemplo de la forma** de un plugin (`.claude-plugin/plugin.json`). La instalación
y distribución de plugins se hace con el mecanismo de plugins/marketplace de Claude Code — revisa la
**documentación oficial** para el flujo vigente, ya que evoluciona.

> En resumen: así es como Claude escala de "un proyecto" a "tu stack reutilizable".
